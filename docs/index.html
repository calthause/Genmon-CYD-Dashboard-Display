Genmon CYD Dashboard

Web installer for the generator monitor display (ESP32 + CYD).

Requirements: Chrome or Edge on a desktop computer, and a USB data cable connected to the ESP32. Web Serial is not supported in Firefox or Safari.

Steps

  1. Plug the display into your computer with a USB data cable.
  2. Click Connect above and select the device’s serial port.
  3. Choose Install and confirm. Flashing takes about a minute.
  4. After flashing, follow the on-screen prompts to connect the display to your Wi-Fi and Genmon monitor.

Source code: github.com/calthause/Genmon-CYD-Dashboard-Display
